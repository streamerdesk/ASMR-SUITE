# Changelog — Streamerdesk ASMR Suite (Linux)

## 1.0.1 — 2026-11-11
- **Nuevo:** primera versión para Linux de la suite completa: Eco Ping-Pong 1.0.1, Reverb 1.0.1, 8D / Órbita 1.0.0, Susurro de oído a oído 1.0.0, Proximidad 1.0.0 y Espacialidad binaural 1.0.0.
- **New:** first Linux release of the complete suite (same six effects and versions).
- Linux x86_64 (glibc 2.28+), OBS Studio 28 o posterior, también OBS Flatpak. / Linux x86_64 (glibc 2.28+), OBS Studio 28 or later, Flatpak OBS included.
- Mismo sonido, presets e interfaz que en Windows y macOS. / Same sound, presets and UI as on Windows and macOS.
- `install.sh` con selector de efectos (todos marcados por defecto) y `uninstall.sh`. Sin `sudo`. Tus presets se conservan. / `install.sh` with an effect picker (all selected by default) and `uninstall.sh`. No `sudo`. Your presets are kept.
