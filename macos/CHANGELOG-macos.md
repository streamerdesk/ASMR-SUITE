# Changelog — Streamerdesk ASMR Suite (macOS)

## 1.0.1 — 2026-11-11
- **Nuevo:** primera versión para macOS de la suite completa: Eco Ping-Pong 1.0.1, Reverb 1.0.1, 8D / Órbita 1.0.0, Susurro de oído a oído 1.0.0, Proximidad 1.0.0 y Espacialidad binaural 1.0.0.
- **New:** first macOS release of the complete suite (same six effects and versions).
- Bundles `.plugin` universales (Apple Silicon arm64 + Intel x86_64), macOS 11+, OBS Studio 28 o posterior. / Universal `.plugin` bundles (arm64 + x86_64), macOS 11+, OBS Studio 28 or later.
- Mismo sonido, presets e interfaz que en Windows. / Same sound, presets and UI as on Windows.
- Instalador de doble clic con selector de efectos (todos marcados por defecto), instalador `.pkg` con opciones por efecto y desinstalador. Tus presets se conservan. / Double-click installer with effect picker (all selected by default), `.pkg` installer with per-effect choices, and uninstaller. Your presets are kept.
- Firmados ad-hoc, no notarizados: mira las instrucciones de Gatekeeper en LEEME-README.md. / Ad-hoc signed, not notarized: see the Gatekeeper notes in LEEME-README.md.
