# Changelog — Streamerdesk ASMR - Reverb

## 1.0.1 — 2026-11-11
- **Corregido:** al cargar un preset ahora se muestran los controles correctos.
- **Fixed:** loading a preset now shows the correct controls.
- Compilado con las cabeceras de OBS 28.0; sin cambios en el sonido ni en los presets. / Built with OBS 28.0 headers; no changes to the sound or presets.

## 1.0.0 — 2026-11-11
Primera versión / First release (Windows x64; Linux y macOS más adelante).

- Reverb algorítmica estéreo para OBS Studio 28+: pre-retardo, difusión de entrada, reflexiones tempranas y cola tardía con red de retardos realimentada (FDN) de 8 líneas.
- Controles: tamaño, duración (0,2–10 s), pre-retardo (0–200 ms), difusión, congelar, amortiguación de agudos, corte de graves/agudos sobre la reverb, balance reflexiones/cola, anchura estéreo, modulación suave, entrada mono/estéreo, ducking (cantidad y recuperación), mezcla seco/húmedo (50 % = ambos al máximo) y volumen de salida.
- 4 presets incluidos (Habitación íntima, Sala suave, Catedral susurro, Placa cálida) y presets de usuario guardados solo en tu ordenador.
- Interfaz bilingüe español / inglés con ayuda (?) en cada control.
- Instalador de Windows bilingüe con detección automática de OBS y desinstalador.
